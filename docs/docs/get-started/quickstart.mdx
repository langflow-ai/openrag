## Install BomaRAG

This quickstart installs BomaRAG with [`uvx`](https://docs.astral.sh/uv/guides/tools/#running-tools) which automatically installs BomaRAG's dependencies as needed, including Docker or Podman.

1. Create a directory for your BomaRAG installation, and then change to that directory:

   ```bash
   mkdir bomarag-workspace
   cd bomarag-workspace
   ```

2. Install BomaRAG and its dependencies with `uvx`.

   ```bash
   uvx --python 3.13 bomarag
   ```

   You might be prompted to install certain dependencies if they aren't already present in your environment.
   The entire process can take a few minutes.
   If you encounter errors during installation, see [Troubleshoot BomaRAG](/support/troubleshoot).

3. Once the environment is ready, the BomaRAG terminal session starts, and begins issuing prompts for BomaRAG configuration settings.

4. For the OpenSearch and Langflow **Admin password** prompts, autogenerate or manually enter passwords.

5. For this quickstart, skip or press <kbd>N</kbd> for all remaining configuration prompts to use the default values.

   Your BomaRAG configuration and passwords are stored in an [BomaRAG `.env` file](/reference/configuration) file that is created automatically at `~/.bomarag/tui`.
   BomaRAG container definitions are stored in the `docker-compose` files in the same directory.

6. At the `Start services now?` prompt, press <kbd>Y</kbd> to start the BomaRAG services.

   This process can take some time while BomaRAG pulls and runs the container images.
   If all services start successfully, the terminal prints a confirmation message:

   ```text
   Services are running.
   ```

7. If the BomaRAG app doesn't launch automatically, select the **Open BomaRAG in browser** option to launch the BomaRAG app and start the application onboarding process.

8. For this quickstart, select the **OpenAI** model provider, enter your OpenAI API key, and then click **Complete**. Use the default settings for all other model options.

9. Click through the onboarding chat for a brief introduction to BomaRAG, or click <Icon name="ArrowRight" aria-hidden="true"/> **Skip overview**.
You can complete this quickstart without going through the overview.
The overview demonstrates some basic functionality that is covered in the next section and in other parts of the BomaRAG documentation.

## Load and chat with documents {#chat-with-documents}

Use the [BomaRAG **Chat**](/chat) to explore the documents in your BomaRAG database using natural language queries.
Some documents are included by default to get you started, and you can load your own documents.

1. In BomaRAG, click <Icon name="MessageSquare" aria-hidden="true"/> **Chat**.

2. For this quickstart, ask the agent what documents are available.
For example: `What documents are available to you?`

   The agent responds with a summary of BomaRAG's default documents.

3. To verify the agent's response, click <Icon name="Library" aria-hidden="true"/> **Knowledge** to view the documents stored in the [BomaRAG OpenSearch knowledge base](/knowledge).
You can click a document to view the chunks of the document as they are stored in the knowledge base.

4. Click **Add Knowledge** to add your own documents to your BomaRAG knowledge base.

   For this quickstart, use either the <Icon name="File" aria-hidden="true"/> **File** or <Icon name="Folder" aria-hidden="true"/> **Folder** upload options to load documents from your local machine.
   **Folder** uploads an entire directory.
   The default directory is `~/.bomarag/documents`.

   For other ingestion options, see [Ingest knowledge](/ingestion).

5. Return to the **Chat** window, and then ask a question related to the documents that you just uploaded.

   If the agent's response doesn't seem to reference your documents correctly, see [Troubleshoot chat issues](/support/troubleshoot#chat-issues).

## Change the language model and chat settings {#change-components}

In BomaRAG, you can change some chat and ingestion settings directly on the **Settings** page.
For full customization capabilities, you can edit the underlying [Langflow flows](/agents) in the BomaRAG's embedded Langflow visual editor.

For this quickstart, try changing the **Language Model** or **Agent Instructions**.
Editing the flow in Langflow is optional.

<PartialEditAgentFlow />

5. Ask the same question you asked in [Load and chat with documents](#chat-with-documents) to see how the response differs from the original settings.

6. To undo your changes, go to **Settings**, and then click **Restore flow** to revert the flow to its original state when you first installed BomaRAG.

## Next steps

* **Reinstall BomaRAG with your preferred settings**: This quickstart used `uvx` and a minimal setup to demonstrate BomaRAG's core functionality.
It is recommended that you [reinstall BomaRAG](/reinstall) with your preferred configuration and [installation method](/install-options).

* **Use the BomaRAG SDKs**: To interact with BomaRAG programmatically, use the [BomaRAG SDKs](/reference/api-sdk-overview).

* **Learn more about BomaRAG**: Explore BomaRAG and the BomaRAG documentation to learn more about its features and functionality.

* **Learn more about Langflow**: For a deep dive on the Langflow API and visual editor, see the [Langflow documentation](https://docs.langflow.org/).
