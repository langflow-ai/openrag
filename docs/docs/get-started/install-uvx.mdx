Use [`uvx`](https://docs.astral.sh/uv/guides/tools/#running-tools) to invoke BomaRAG outside of a Python project or without modifying your project's dependencies.

This installation method is best for testing BomaRAG by running it outside of a Python project.
For other installation methods, see [Select an installation method](/install-options).

When you install BomaRAG with `uvx`, you will use an [BomaRAG terminal session](/tui) to configure and manage your BomaRAG deployment.

:::info
`uvx bomarag` installs the latest version of BomaRAG and dependencies, like Docker or Podman, if they aren't already present in your environment.
:::

## Install and run BomaRAG with uvx

1. Create a directory for your BomaRAG configuration files and data, and then change to that directory:

   ```bash
   mkdir bomarag-workspace
   cd bomarag-workspace
   ```

2. Optional: If you want to use a pre-populated [BomaRAG `.env` file](/reference/configuration), create one at `~/.bomarag/tui` before invoking BomaRAG.

3. Invoke BomaRAG and install any missing dependencies:

   ```bash
   uvx --python 3.13 bomarag
   ```

   You can invoke a specific version using any of the [`uvx` version specifiers](https://docs.astral.sh/uv/guides/tools/#requesting-specific-versions), such as `uvx --from bomarag==0.1.30 bomarag`.

   <PartialStartTui />

4. If needed, respond to any prompts to install and configure dependencies like Docker or Podman.

The entire setup process can take a few minutes.
Once the environment is ready, the BomaRAG terminal session starts.

Invoking BomaRAG with `uvx bomarag` creates a cached, ephemeral environment for the terminal session in your local `uv` cache.
Your BomaRAG configuration files and data are stored in `~/.bomarag`, which is separate from the `uv` cache.
Clearing the `uv` cache doesn't remove your entire BomaRAG installation; it only clears `uv` dependencies.
After clearing the cache, you can re-invoke BomaRAG (`uvx bomarag`) to restart the terminal session with your preserved configuration and data.

If you encounter errors during installation, see [Troubleshoot BomaRAG](/support/troubleshoot).

## Configure BomaRAG in the terminal {#setup}

When you install BomaRAG with `uvx`, you manage the BomaRAG services in an BomaRAG terminal session.
The terminal session guides you through the initial configuration process before you start the BomaRAG services.

Your configuration values are stored in an [BomaRAG `.env` file](/reference/configuration) that is created automatically at `~/.bomarag/tui`.
If BomaRAG detects an existing `.env` file in this directory, then BomaRAG can populate those values automatically during setup and onboarding.

Container definitions are stored in the `docker-compose` files in the same directory as the BomaRAG `.env` file.
