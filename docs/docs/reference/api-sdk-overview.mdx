Use the BomaRAG SDKs to interact with BomaRAG programmatically or integrate BomaRAG into an application:

* [MCP API (streamable-HTTP endpoint)](https://github.com/ABISHAIMWANJA/bomarag/tree/main/sdks/mcp)

   Connect your MCP client directly to your running BomaRAG instance at `/mcp`.

   The standalone `bomarag-mcp` package is deprecated; use the built-in endpoint instead.

* [Python SDK](https://github.com/ABISHAIMWANJA/bomarag/tree/main/sdks/python)

* [TypeScript/JavaScript SDK](https://github.com/ABISHAIMWANJA/bomarag/tree/main/sdks/typescript)

* [Core BomaRAG APIs (`main.py`)](https://github.com/ABISHAIMWANJA/bomarag/blob/main/src/main.py)
